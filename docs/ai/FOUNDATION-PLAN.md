# PVE 决策架构第一阶段

目标：复用同一组观察、规则、意图和原生执行契约，支持职业基础规则、野外/副本场景覆盖和团队遭遇分工；避免将全部行为塞入一个 JSON 或重写既有 AI。

本轮范围：
- 与游戏对象解耦的值类型 Observation/Scope/Intent、执行接口、资源仲裁和有界事件记录。
- 严格版本化 JSON 规则解析、字段/能力注册目录、条件/分数/场景覆盖与不可变策略快照；坏配置保留旧快照，显式安全边界发布。
- 每团队/地图/副本/遭遇实例隔离的共享阶段、稳定职责分配和战斗期间策略版本固定；纯 C++ 模块注册扩展。
- 原生 PartyBot 观察适配的可选 shadow 接入；默认关闭，仅比较决策、不执行新动作。现有 PVP 和 PVE 行为保留，不声称已统一迁移。
- 独立测试和完整服务端编译，文档与评审。仅源码候选发布，不部署或重启生产。

暂不迁移全职业循环/全Boss策略，不实施外部模型/RL，不新增数据库结构或客户端依赖。新字段、能力、动作执行仍须 C++ 注册并原生校验；JSON 无SQL、GM、任意函数和绕过CD/GCD权限。

验收重点：缺字段失败关闭；配置错误/重复键不破坏旧版本；场景与TTL过期意图拒绝；移动/施法/交互冲突与抢占可解释；遭遇跨组隔离、职责稳定、阶段有最短停留、单 tick 最多一次转换，不做无界转换循环；重载不能半场改变团队布局；shadow不改变真人/怪物状态且不写账号数据。并发/规模性能及所有副本实战不在本轮完成声明中。
