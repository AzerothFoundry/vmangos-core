# 后台材料供货

不需要一个AI角色站在拍卖行挂机。独立普通卖家离线即可，玩家在原拍卖行购买，通过原生拍卖邮件领取物品。仅使用已有角色、物品、拍卖、邮件行，不建表、不改字段或索引；原AHBot保持关闭。

集成：将 `AuctionHouse/MaterialSupply.cpp` 加入game构建；World.cpp包含 `MaterialSupply.h`，在现有每分钟拍卖维护块内、`sAuctionMgr.Update()`之后调用 `MaterialSupply::Update()`。无需启动Load调用。仅在World线程调用。

配置示例（默认禁用）：

```ini
AHBot.Enable = 0
MaterialSupply.Enable = 0
MaterialSupply.SellerGuid = 0
MaterialSupply.ConfigFile = "/workspace/vmangos/material-supply.csv"
MaterialSupply.IntervalSeconds = 60
MaterialSupply.MaxAddsPerTick = 30
```

启用前由管理员单独创建普通账号和卖家角色，填角色低GUID。不要用Root、WEB_SERVICE或GM角色；买家不能与卖家共用账号，游戏原生禁止同账号购买。模块每周期核实角色存在、未删除、当前realm/-1有效account_access普通权限（直接查询，不依赖缓存或legacy列）；缺失/异常配置明确日志并停止该周期新增，不拿其他角色兜底。

CSV每行：`物品ID,每组数量,每个拍卖池目标组数,整组一口价铜币`，允许行尾 `#` 注释。示例价格仅为本地测试，不是市场估值；10000铜=1金。示例所有ID与堆叠上限已查询当前patch10模板，矿石每组10而不是20。

白名单限定经典版布、皮/鳞片/毛皮、矿石/锭/石头、草药、附魔与基础元素材料；不接受任意装备、配方或TBC材料。代码还验证当前patch物品模板、贸易品类别、非NOT_OBTAINABLE、合法堆叠、唯一行、目标1–5组、一口价1–100000000铜，总计最多128行；间隔60–86400秒、每周期1–50条新增。CSV整份验证通过才写入拍卖。建议先保持每种2组、每周期30条。配置变更通过原服务器reload config读入；CSV每周期重读，推荐写临时文件后原子替换。

联盟/部落/中立三池按真实拍卖对象去重。只统计该卖家、该物品、未过期拍卖，缺几组补几组；轮转遍历避免前几种材料占完补货上限。已有玩家拍卖不计库存、不删除、不改价、不收购。修改CSV价格只影响未来新增，已有挂单保持原价；减少目标或禁用也不撤已有挂单。

挂单48小时，直接买断价等于起拍价，系统供货不扣卖家资金且保证金为0，避免退款凭空增加保证金。成交款、手续费、流拍退货及邮件过期继续原生流程。卖家邮箱可能有收入和流拍材料；模块不会清理或重新利用其邮件，长期运维可定期检查。它不是玩家经济模拟器。

实现复用原生物品创建、拍卖索引及购买邮件流程。整周期先预准备全部物品/拍卖，拒绝嵌套事务、检查Begin，单次CommitTransactionDirect真实执行成功后才发布内存索引；失败由RAII销毁临时对象并归还auction ID，避免未保存的ghost拍卖。真实购买、重启持久化和邮件领取仍需部署后的隔离账号验收，编译不能代替实际成交验证。
